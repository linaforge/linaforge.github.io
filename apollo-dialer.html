Apollo Call List

Drop an Apollo CSV export and every number becomes a click-to-call link.

Dialing method

  1. Install the Google Voice extension (built by Google). Click Add to Chrome.
  2. Reload this page. The extension scans for phone numbers and adds a green Voice icon next to each one.
  3. Click the icon to call. This uses the extension, not the tel: handler, so it sidesteps the problem entirely.
Numbers are rendered as plain text in this mode so the extension can detect them cleanly.
One-click dialing won't work here. This page is open from a local file (file://), and Chrome won't pass tel: links to Google Voice from a local file — it hands them to Windows instead, which is what the “Pick an app” popup was. Your Voice registration is fine; it just can't be reached this way.

Use Google Voice web below instead. One extra click per call, but it works right now.
  1. Open this page in Chrome over https:// or http://localhost. Chrome ignores tel: handlers on local files.
  2. Register Google Voice for one-click dialing, then click Allow when Chrome prompts.
  3. Verify: Chrome › Settings › Privacy and security › Site Settings › Additional permissions › Protocol handlers. You should see voice.google.com under “Tel”.
Google account slot:
Check an open Google Voice tab — if its URL contains /u/1/, pick u/1. Wrong slot sends you to the Voice marketing page.
